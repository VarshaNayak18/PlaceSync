# PlaceSync

A full-stack campus placement management platform designed to streamline the recruitment process between students, placement officers, and companies.

---

### Tech Stack

#### Backend
- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- Hibernate
- MySQL

#### Frontend
- React
- Vite
- Axios

---

### Planned Features

- JWT Authentication
- Role-Based Access Control
- Student Profile Management
- Company Management
- Job Posting and Management
- Job Applications
- Automatic Eligibility Checking
- Interview Scheduling
- Placement Tracking
- Dashboard Analytics
